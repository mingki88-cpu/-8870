3. 학생들과 쓰기 (약 15분)

1단계온라인 주소 만들기

학생 태블릿에서 열려면 인터넷 주소가 필요해요. 둘 중 하나를 고르세요.

  • 깃허브 페이지(추천) — 깃허브에서 공개(Public) 저장소를 만들고 Add file → Upload files에 이 폴더 안의 파일과 폴더를 모두 끌어다 놓기(araho-solar 폴더 자체가 아니라 내용물을, zip 그대로가 아니라 압축을 푼 것을) → Settings → Pages에서 Branch를 main으로 저장. 1~2분 뒤 아이디.github.io/저장소이름 주소가 생겨요. 나중에 고쳐도 주소가 그대로예요.
  • 넷리파이 드롭 — app.netlify.com/drop에 로그인한 뒤 이 폴더를 통째로 끌어다 놓기.

2단계구글 시트 연결 (기록 저장·교신·AI)

  1. 새 구글 시트를 만들고 메뉴 확장 프로그램 → Apps Script를 열어요.
  2. 편집기 내용을 모두 지우고 Code.gs 파일 내용을 통째로 붙여넣은 뒤 저장해요.
  3. 배포 → 새 배포 → 유형: 웹 앱을 고르고, 실행 사용자는 나, 액세스 권한은 모든 사용자로 배포해요. 권한 허용 창이 뜨면 허용해요.
  4. 나온 웹 앱 URL(…/exec로 끝남)을 복사해요.
  5. index.html을 메모장(또는 깃허브의 ✏️ 편집)으로 열어 Ctrl+F로 const API를 찾아 const API = ''; 따옴표 안에 붙여넣어요. (화면 꾸미기 코드 아래, 400여 번째 줄에 있어요)

3단계우리 학교 이름 넣기

index.html의 const API 줄 바로 아래에 있어요.

const SCHOOL = '우리';            → 예: '고천'   (관제센터 이름·미션 패치, 두 글자 추천)
const SCHOOL_FULL = '우리 학교';  → 예: '고천중학교'
const SCHOOL_EN = 'ARAHO';        → 예: 'GOCHEON' (첫 화면 영문)
const SCHOOL_STORY = '';          → 첫 화면에 넣을 학교 이야기 (비워 둬도 됨)

선택공개수업 참관 모드

입장 화면 아래 '🎩 참관 오셨나요? 둘러보기'로 참관 선생님이 둘러보기 전용으로 들어올 수 있어요. 슬라이드를 잠금 없이 넘기고 활동을 해 볼 수 있지만, 시트에도 기기에도 아무것도 저장되지 않아요. 교신 채널은 그 반 학생들의 교신을 이름을 가린 채 보여 줘요.

const GUEST_CLS = ['1'];   → 참관할 반. 예: ['3'] / 여러 반 ['1','2'] / 끄기 []

4단계센터장 코드와 AI 키

Apps Script 웹 앱을 한 번 열면 시트에 설정 탭이 생겨요.

  • PIN — 센터장(교사) 화면 입장 코드. 처음 값 1234를 꼭 바꾸세요.
  • GEMINI_KEY — aistudio.google.com에서 무료로 발급한 키를 넣으면 논술 AI 코치가 켜져요. 키는 시트 안에만 있고 학생 기기에는 전달되지 않아요.

선택학생 명단

시트에 아무 탭이나 만들어 첫 줄에 반 | 번호 | 이름을 쓰고 명단을 붙여넣으면, 학생은 반·번호를 고르고 자기 이름을 확인한 뒤 콜사인(첫 입장 때 스스로 정하는 비밀번호)으로 들어와요. 명단이 없으면 반·번호·이름을 직접 입력해서 들어와요.

4. 쓰면서 알아 두실 점

  • 학생 기록은 시트의 학생(현재 점수·진도)·기록(모든 글과 AI 피드백) 탭과 문항별 탭에 쌓이고, 앱의 센터장 탭에서 실시간으로 볼 수 있어요.
  • MISSION 02 관제팀 분류 회의에서 모둠이 보고하면, 우리 반 다른 모둠들의 분류 결과(1팀·2팀, 기준, 설명)와 "같은 두 무리로 나눈 팀 수"가 바로 아래에 나타나요. 보고 내용은 시트의 교신 탭에 '분류회의' 단계로 저장되고, 교신 채널 화면에는 나오지 않아요.
  • 학생 이름은 입장 화면과 교신 목록에서 가운데 글자를 가려 보여요(김민준 → 김○준). 서버가 처음부터 가린 이름만 보내므로, 참관 오신 분이나 다른 사람이 화면을 눌러 봐도 전체 이름은 알 수 없어요. 센터장 화면에서만 전체 이름이 보여요.
  • 교신 채널은 기본으로 자기 반 교신만 보이고, '다른 반 교신 구경하기'를 누르면 이름을 가린 채 읽기만 할 수 있어요.
  • 내용은 2022 개정 교육과정 [9과07-01]·[9과07-02]와 천재교육 교과서 226~235쪽을 기준으로 맞췄어요. 밀도는 교육과정상 다음 단원(물질의 특성)에서 배우므로 '더 알아보기' 한 장에만 있고 평가에서는 요구하지 않아요.
  • 센터장으로 들어가서 해 본 활동은 저장되지 않고, 다시 들어가면 처음 상태로 시작해요.
  • Code.gs를 고친 뒤에는 Apps Script에서 배포 → 배포 관리 → 수정(연필) → 새 버전으로 다시 배포해야 반영돼요. URL은 그대로예요.
